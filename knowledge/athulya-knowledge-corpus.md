- Skills: grouped skill cards.
- Education: degree, activity, and certification cards.
- Footer: email, GitHub, and CV link.

Navigation behavior:

- Desktop toolbar is a slim fixed top toolbar.
- Mobile toolbar is fixed at the bottom.
- On mobile, the menu button is centered, the theme toggle is on the right, and the name is on the left.
- Internal section links scroll smoothly to page sections.
- External/action links open in a new tab.

Visual behavior:

- The page uses glass-like cards over layered pixel-art background images.
- AOS is used for most section/card entrance animations, but not for the top/bottom toolbar or footer.
- The site has light and dark modes.
- Weather buttons switch between clear, rain, and snow particle themes.
- The adventurer GIF links secretly to Athulya's Wattpad profile.

- The background-image color changes use CSS filter techniques as a workaround for CSS not naturally recoloring raster images. The idea is to combine filters such as `sepia()` and `hue-rotate()` to push the existing pixel-art background into different color moods, then pair that with brightness, contrast, saturation, and opacity adjustments where needed. This lets the same background art support theme and weather variations without needing a separate recolored image for every state.

- If the user asks to open a public profile, project, article, CV, or external page, send only the matching `/open-link` command.
- If the user asks a normal question, answer normally and do not send a command.
- If the user asks for both an explanation and navigation, answer the explanation normally first. Do not send a command unless the frontend supports command-plus-message behavior.
